Implementation Guide for Course Mentors

1. Environment & Cloud Configuration

Configured with Flask 3+, Boto3 SDK, python-dotenv, and Gunicorn. Supports instant credential loading via .env with support for standard IAM access keys and AWS Academy session tokens.

Files: config.py, services/aws_client.py

2. Cloud Database (Amazon DynamoDB)

Four decoupled DynamoDB tables with partitioned keys (PatientID, DoctorID, AppointmentID, DiagnosisID) delivering sub-millisecond retrieval with secondary scan filters.

Files: services/db_service.py, deploy/dynamodb_setup.py

3. Flask Application Core Workflows

Complete user journeys: Patient self-registration, Doctor clinical access, interactive scheduling with physician slot availability, and clinical diagnosis entry with medical prescription builder.

Files: app.py, templates/, static/

4. Cloud Notifications (AWS SNS)

Dispatches automated event messages upon appointment booking and diagnosis release. Real-time bell modal in the UI displays published notification events with message attributes.

Files: services/sns_service.py

5. Secure Access Control with IAM

Granular role separation between Patients and Clinicians. Pre-crafted IAM policy JSON grants least-privilege permissions targeting only MedTrack DynamoDB tables and SNS topics.

Files: deploy/iam_policies.json

6. Production Deployment on AWS EC2

Includes Nginx reverse-proxy setup, Gunicorn WSGI configuration, systemd daemon service, and automated setup_ec2.sh shell script ready for Amazon Linux 2023.

Files: deploy/nginx.conf, deploy/medtrack.service, deploy/setup_ec2.sh

7. Testing & Verification

Integrated demo logins, sample records, and instant appointment booking and diagnosis test cycles to simulate real-world patient-doctor interaction without external dependencies.

Ready: 1-click test fill on login page

8. Monitoring & Optimization (CloudWatch)

Emits custom CloudWatch application metrics (APPOINTMENT_BOOKED, DIAGNOSIS_SUBMITTED, USER_LOGIN) and writes immutable security audit logs to data/audit_trail.jsonl.

Files: services/cloudwatch_logger.py

Ready for AWS Credits: 3 Steps to Go Live

When you receive your AWS student/lab credits, you do not need to change a single line of application code. Simply follow these three steps:

  1. Create DynamoDB Tables: Run python deploy/dynamodb_setup.py using your AWS credentials to automatically create the 4 tables in your AWS Region.
  2. Configure .env: Set USE_AWS=True and enter your AWS_ACCESS_KEY_ID, AWS_SECRET_ACCESS_KEY, and AWS_REGION.
  3. Run or Deploy: Start the Flask server locally or execute deploy/setup_ec2.sh on your EC2 instance. The application immediately reads and writes to live AWS services!
